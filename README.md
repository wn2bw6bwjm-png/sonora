# SONORA

Личная музыкальная библиотека: альбомы, оценки, рецензии, коллекции, статистика. Работает офлайн, данные хранятся только на устройстве. Встроенной музыки и каталога нет: всё, что вы видите, добавили вы сами.

## Локальный запуск
```
flutter create . --org com.sonora --project-name sonora --platforms=android,ios
python3 tool/configure_platforms.py   # интернет и фоновое аудио в Android/iOS
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter run
```
`flutter test`: `backup_test.dart` требует системную sqlite3 (на Linux: `sudo apt install libsqlite3-dev`).

## Сборка через GitHub Actions
Загрузите папку проекта в корень репозитория и запустите workflow «Build SONORA» (вкладка Actions, Run workflow).
- `sonora-apk` — release APK, подписан debug-ключом, ставится напрямую.
- `sonora-ipa-unsigned` — IPA без подписи. Для установки её нужно подписать своим Apple ID (Sideloadly, AltStore) или собрать с сертификатом.
Шаги analyze и test не блокируют сборку: их результат смотрите в логе.

## Шрифты (по желанию)
Положите Newsreader и Inter (OFL) в `assets/fonts/` и добавьте в pubspec секцию `fonts:`. Без них используется системный шрифт.

## Архитектура
`lib/core` тема, роутер, утилиты · `lib/domain` сущности и чистая логика (рекомендации, статистика) · `lib/data` Drift-БД (схема v6, миграции), репозитории, бэкап · `lib/presentation` экраны · `lib/player` аудио-движок и контроллер · `lib/shared` общие виджеты.

## Ручная проверка сценариев
1. Первый запуск: онбординг, «Пропустить» и полный путь до «Начать».
2. Library: добавить альбом с жанрами и треклистом, изменить, удалить.
3. Альбом: оценка слайдером, сброс, рецензия, избранное, история оценок.
4. Коллекции: создать, добавить и убрать альбомы, переименовать, удалить.
5. Исполнитель: переход с альбома, дискография, средняя оценка.
6. Discover: подборки строятся из вашей библиотеки (рекомендации по оценкам, неоценённые, не слушали недавно, жанры).
7. Поиск: запрос, фильтры, история, очистка истории.
8. Stats: числа и графики меняются после новых оценок.
9. Library → Tracks → «+»: добавьте сразу несколько своих файлов как отдельные треки. Сверните приложение во время игры: звук должен продолжаться, в шторке есть пауза.
9a. Плеер: «Слушать», пауза, перемотка, очередь, mini-player. Прикрепите свой аудиофайл к треку (меню трека на странице альбома) и убедитесь, что слышен звук; у трека без файла идёт беззвучный таймлайн.
10. Настройки: смена темы, экспорт, импорт, восстановление из копии.
11. Library: все 6 вкладок, плейлисты (создать, добавить трек через меню трека, слушать), избранные треки и исполнители.
12. Своя обложка альбома, фото и биография исполнителя, обложка коллекции.
13. Планшет или широкий экран: библиотека показывается сеткой.
14. Перезапуск приложения: все данные на месте.

## Известные ограничения
Аудио воспроизводится только из ваших локальных файлов (прикрепляются к трекам на странице альбома). Аудиофайлы не входят в JSON-бэкап (слишком большие), картинки входят. Фоновое воспроизведение работает для треков с прикреплённым файлом (уведомление и экран блокировки: пауза и перемотка; переключение треков только в приложении). Требует `tool/configure_platforms.py` после `flutter create`. Обложки и фото по ссылке работают только по https и требуют сети; в Android-сборке для этого нужно разрешение INTERNET (workflow добавляет его сам, при локальной сборке добавьте в AndroidManifest.xml).
